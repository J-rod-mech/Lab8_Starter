Using Service Workers is a lower level extension of web development that allows for added functionality and resilience with network issues. Although it is good to have, you should first ensure the primary functionality of your site's JavaScript, CSS, and HTML. Messing with the cache during development without knowing if your site is first working at a basic level could introduce unforeseen errors, which is why Service Workers should be addressed later, with grace.
